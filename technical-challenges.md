# Engineering challenges and verification

| Area | Engineering concern | Evidence to collect before claiming completion |
| --- | --- | --- |
| Catalog | Product options and category filtering | Browser-based functional tests |
| Cart | Price and quantity consistency | Validation tests and edge cases |
| Orders | Duplicate submission and state transitions | Controlled integration tests |
| Admin | Access boundaries and permissions | Role-based test matrix |
| Data | Server-side validation and consistency | Database integration tests |
| Reliability | Network interruptions and retries | Failure-injection test logs |
| Responsiveness | Mobile and desktop layouts | Screenshots at multiple viewport sizes |

Do not publish raw logs, real order IDs, customer data or production configuration as test evidence.
